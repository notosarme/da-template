# DeviantArt Inspired Template for Personal Websites

A template created in 11ty for use with personal webpages.

Based most heavily on the well-loved 2010s style of the site, with some influences of other eras. WebArchive examples I used as references are linked.
- ~2007 style for the [artwork display](https://web.archive.org/web/20070809060436/http://www.deviantart.com/deviation/54281761/?qo=1&qh=special%3Apopular) and [journal](https://web.archive.org/web/20120129115519/http://garun.deviantart.com/journal/) (posts/about).
- ~2012 style for [gallery](https://web.archive.org/web/20111120093219/http://namie-kun.deviantart.com/gallery), [artwork display](https://web.archive.org/web/20130413042344/http://behindinfinity.deviantart.com/art/Death-Note-This-Is-Heaven-52682456), [profile](https://web.archive.org/web/20120127023041/http://garun.deviantart.com/), and [journal](https://web.archive.org/web/20091018042403/http://gofu-web.deviantart.com/journal/).
- Optional Eclipse style [folder placement](https://web.archive.org/web/20221208052559/https://www.deviantart.com/dededes/gallery) (horizontal in the gallery)
